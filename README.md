# Contact Us

A simple React contact page for a support or customer service experience. The app includes a navigation bar, page heading, support contact options, and a contact form with a branded illustration.

## Features

- Responsive navigation menu
- Contact page hero section
- Support channel buttons for chat, call, and email
- Contact form with name, email, and message fields
- Styled layout using custom CSS
- Built with React and Create React App

## Tech Stack

- React
- React Icons
- CSS
- Create React App

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd contactus
```

2. Install dependencies:

```bash
npm install
```

### Run the App

```bash
npm start
```

This will start the development server and open the app in your browser at:

```text
http://localhost:3000
```

## Available Scripts

```bash
npm start
```
Runs the app in development mode.

```bash
npm test
```
Launches the test runner in interactive mode.

```bash
npm run build
```
Creates a production build in the `build` folder.

## Notes

This project currently focuses on the front-end UI for the contact page. It does not include a backend for actual form submission or email processing yet.
